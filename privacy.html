Privacy Policy

Last updated: September 19, 2026

This Privacy Policy explains how personal data is handled when you use Random Frame.

1. Data Controller

The data controller is:

Adrian Mokrzycki
Contact: contact@amokrzycki.ovh

2. Data Collected by Random Frame

Random Frame is designed to collect as little user data as possible.

The application does not:

  • create user accounts,
  • use advertising or marketing trackers,
  • store users' IP addresses in application logs, access logs, analytics logs or error logs,
  • maintain a database of visitors,
  • profile users.

The server infrastructure may temporarily process an IP address as technically necessary to establish a network connection, route requests and protect the service against abuse. Random Frame does not retain these IP addresses in its own logs.

3. Local Browser Storage

Random Frame may use browser storage such as localStorage or sessionStorage for functionality provided directly in the user's browser.

This data may include:

  • acknowledgement of the entry notice,
  • recently displayed Random Frame item identifiers or browsing history used by the application.

This information remains in the user's browser and is not used for analytics, advertising or user profiling.

Users can remove this information at any time by clearing their browser's site data.

4. Cloudflare

Random Frame uses Cloudflare to provide network proxying, security and protection against abuse.

When a user connects to Random Frame, the connection passes through Cloudflare. As part of providing these services, Cloudflare may process technical information such as:

  • IP addresses,
  • request and routing information,
  • timestamps,
  • browser and device information,
  • security-related information.

Random Frame also uses Cloudflare Web Analytics, including its Real User Monitoring (RUM) beacon, to understand aggregated website usage and performance.

The beacon processes page-view and performance information such as page URLs, referrers, page-load timings, a generated page-load identifier, and browser, operating system and device information. This information is sent to Cloudflare for processing.

According to Cloudflare, the beacon does not read or store cookies, localStorage, sessionStorage or IndexedDB, and does not fingerprint individual users. Cloudflare receives the source IP address as part of normal request handling but states that it discards the address at the nearest Cloudflare data center without storing it in its core databases or logs.

Random Frame uses the resulting aggregated metrics to understand website usage and performance, not for advertising, marketing or user profiling.

Cloudflare states that unsampled beacon data is retained for seven days and is then aggregated for longer-term storage.

Cloudflare processes this information according to its own privacy and data-processing policies.

Cloudflare Web Analytics information:
https://developers.cloudflare.com/speed/observatory/rum-beacon/

Cloudflare privacy information:

Random Frame may display or provide links to content originating from external services.

Opening an external website or resource may cause that third party to receive technical information such as your IP address and browser information. The processing of data by those services is governed by their respective privacy policies.

Random Frame does not control the privacy practices of external websites.

  • request deletion of personal data,
  • request restriction of processing,
  • object to certain processing,

Because Random Frame does not maintain user accounts or visitor databases, it may not hold data that allows an individual visitor to be identified.

Requests concerning personal data can be sent to:

9. Cookies

Random Frame does not use advertising or analytics cookies.

If browser storage is used for functionality such as remembering an entry notice or maintaining session history, it is used only for providing application functionality and not for tracking users across websites.

Random Frame is designed to collect as little user data as possible.
